# Boncuk Games — GitHub Pages

Bu paket tek bir GitHub Pages deposunun kök dizinine konulmak üzere hazırlanmıştır.

- `index.html`: Beyaz arka planlı “Çok Yakında” anasayfası.
- `gizlilik-politikasi.html`: Aynı tasarımda bağımsız gizlilik politikası sayfası.
- `styles.css`: Her iki sayfanın paylaştığı stiller.
- `assets/boncuk-logo.svg`: Kullanıcının verdiği özgün Boncuk logosu.

Anasayfada **gizlilik politikasına yönlendiren bir bağlantı veya görünen URL bulunmaz**. Gizlilik politikası dosyası bağımsız olarak erişilebilir; Google Play Console'da ilgili sayfanın adresini belirtmeniz gerekir.

## Yayın öncesi zorunlu kontrol

`gizlilik-politikasi.html` içindeki `[İLETİŞİM E-POSTASI EKLENECEK]` ifadesini gerçek ve çalışan bir iletişim e-postasıyla değiştirin. AdMob / Play Games veri açıklamalarının yayın sürümünüzdeki işlemlerle tutarlı olduğunu onaylayın.

Dört öğeyi (`index.html`, `gizlilik-politikasi.html`, `styles.css`, `assets/`) depoya yükleyin. Harici bağımlılık veya JavaScript kullanılmamıştır.
